# Remove-CWCUser

## SYNOPSIS
Deletes an internal user.

## SYNTAX

```
Remove-CWCUser [-User] <String> [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Calls SecurityService.DeleteUser.

## EXAMPLES

### EXAMPLE 1
```
Remove-CWCUser -User 'jdoe'
```
